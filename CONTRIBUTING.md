# Contributing Guide

Thanks for your interest in contributing! This guide covers how to submit changes to this repository.

## How to Contribute

- **Open an issue first** when you want to propose a change or report a problem, so maintainers can discuss the approach before you start writing code.
- **Create a feature branch** off `main` using a descriptive name (e.g., `add-contributing-guide`, `fix-login-crash`).
- **Keep pull requests small and focused** — one goal per PR makes review faster and simpler.
- **Write a clear pull request description** that explains what changed, why it matters, and how to test it.
- **Request a review** from a maintainer once your branch is ready, and reply to feedback promptly.
- **Follow the project conventions** for branch naming, commit messages, and code style outlined in this guide.

## Getting Help

If you are unsure about anything, ask in the issue or pull request conversation — maintainers are happy to help.
