# Contributing Guide

Thanks for your interest in contributing to this project! This guide covers how to report issues, submit pull requests, and get your changes merged.

## Reporting Bugs and Requesting Features

- Before opening an issue, search existing issues to avoid duplicates.
- Use the GitHub issue tracker for bugs and feature requests only; use discussions for questions.
- Include steps to reproduce, expected behavior, and actual behavior when filing a bug.

## Pulling Requests (PRs)

- Create a new branch for each change (e.g., `add-contributing-guide-2`).
- Keep pull requests small and focused on a single concern.
- Write a clear PR description explaining what changed and why.
-请求 a review from a maintainer before marking the PR ready for merge.

## Review & Merge Expectations

- Maintainers will review pull requests within a few business days.
- Address review feedback promptly and push follow-up commits to the same branch.
- Once approved, a maintainer will merge the pull request into `main`.

## Code of Conduct

- Be respectful and inclusive in all interactions.
- Follow the project's existing style and conventions.
