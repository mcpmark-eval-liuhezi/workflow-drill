# CONTRIBUTING

Thanks for your interest in contributing! This guide covers our basic contribution workflow.

## How to contribute

1. **Start with an issue** — file a bug report or feature request before writing code.
2. **Create a branch** — branch off `main` using a descriptive name (e.g., `add-contributing-guide`).
3. **Make your change** — commit loose changes and open a pull request into `main`.
4. **Request a review** — submit a review on the pull request; maintainers will comment or approve.
5. **Close out** — once merged, the associated issue is closed as completed.
