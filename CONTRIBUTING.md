# Contributing to this repo

- **Start with an issue.** Open an issue describing the change before writing any code, so maintainers can agree on the approach.
- **Work on a descriptive branch.** Create a branch named after the change (e.g. `add-contributing-guide`) off the default branch.
- **Keep pull requests small.** One logical change per PR, with a clear title and a short description that links the related issue.
- **Request a review.** Every PR needs at least one review before it can be merged; respond to feedback on the review threads.
- **Close the loop.** Once merged, link the PR in the issue and close the issue as completed.
